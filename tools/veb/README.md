# Вебхук чтения таблицы и скрипты Google

Вебхук — маленький скрипт Apps Script (`Code.gs`), который ставится **в копию** таблицы и по ссылке с ключом отдаёт
её устройство в JSON: листы, служебные строки и заголовки, формулы, выпадающие списки, скрытые столбцы. Данные
под заголовками не отдаются — только отметка «ячейка заполнена». Ничего в таблице не меняет.

Из JSON на стенде собирается то же `struktura.yaml`, что из выгрузки xlsx:
`python3 inst/src/skripty/import_listy.py proekta=raw/veb/proekta-<дата>.json --check`.

## Маска

Если в копии есть лист **«Маска»** (другое имя — свойство скрипта `MASK_LEGEND`), вебхук отдаёт и значения ячеек
данных — по цвету их заливки:

| Лист «Маска», со 2-й строки | |
|---|---|
| A | ячейка, залитая цветом (цвета — из палитры Google Таблиц) |
| B | смысл: `можно`, `тег` или `нельзя` |
| C | имя тега — для `тег` (например `postavshchik`) |

- `можно` — значение отдаётся как есть;
- `тег` — вместо значения `[[postavshchik-3]]`: одинаковые значения получают один номер, связь видна, само значение — нет;
- `нельзя` и всё незалитое — не отдаётся.

Если твоя таблица-маска устроена иначе — скажи как, переделаю под неё.

## Поставить (делает директор)

**Вручную, без clasp:**
1. Сделать копию шаблона (или проекта) — работаем только с копией.
2. В копии: Расширения → Apps Script → новый файл `orb_veb` → вставить `Code.gs`. Если в проекте уже есть функция
   `doGet` — остановиться и сказать мне.
3. Настройки проекта → Свойства скрипта → `KEY` = любая длинная случайная строка.
4. Развернуть → Новое развёртывание → Веб-приложение: «Выполнять от моего имени», доступ «Все». Скопировать адрес.
5. На стенде создать `~/.config/orb-work/veb` (я его не открываю):

   ```
   proekta_URL=<адрес веб-приложения>
   proekta_KEY=<тот же KEY>
   ```

**Через clasp:**
1. Один раз: [включить Apps Script API](https://script.google.com/home/usersettings), на стенде `make clasp-login`
   (ссылку открыть на ноутбуке, код вставить обратно).
2. `make gas-pull ID=<scriptId копии> NAME=kopiya-shablon` — код копии в `raw/gas/kopiya-shablon/`
   (scriptId — в Apps Script: Настройки проекта → Идентификаторы).
3. `make gas-kopiya NAME=kopiya-shablon` — пометить как копию; без пометки запись не пойдёт.
4. `make veb-push NAME=kopiya-shablon` — вебхук добавится к коду копии, ничего не удаляя.
5. Дальше — шаги 3–5 из ручного способа.

## Забрать

`make veb-zabrat IMYA=proekta` (один лист — `LIST="5-5 Оформление сделок"`) → `raw/veb/proekta-<дата>.json`.
На экран — только сводка: листы, ячейки, формулы, маска. Адрес и ключ не печатаются.

## Безопасность

- Ключ и адрес — секрет: знает ключ — читает устройство таблицы. Сменить: новый `KEY` в свойствах скрипта.
- `make test` проверяет `Code.gs` на заглушке (`proba.js`): данные и «нельзя» не уходят, теги согласованы.
- Запись скриптов (`gas-push`, `veb-push`) — только в папки с пометкой копии; в рабочие таблицы — никогда без твоей команды.
