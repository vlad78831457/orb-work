В столбце C строк 1–9 стоят метки: `header_first`, `key`, `formulaColl` / `formulaFree` / `formulaCell`, `var_key`, `var_name`, `var_value`, `hide_col` (в выгрузке иногда `header_07`), `header_08`, `header_last`.

- **Строка 2** — служебные имена столбцов (`Номенклатура`, `НазваниеТовараПоДоговору`, `Группа_5_2`…). По ним, судя по всему, скрипты и формулы находят столбцы.
- **Строка 3** — вид столбца: `formulaColl`, `formulaFree`, `formulaCell`.
- **Строка 7** — отметки `Скрыть`, `Сгрупировать`, `СкрытьСгрупировать`.
- **Строка 10** — заголовки для людей; **с 11-й** — данные.

Ответ директора (2026-10-13): строки читают скрипты; три вида столбца описаны в части `zna.lis-sluzhebnye-stroki`.

## Чего в отрывке нет

- Листы, на которые ссылаются формулы, но которых нет: «1-2 Запросы по товарным группам», «10 - Настройки проекта», «3-3 Выбор поставщиков», «4-1 Расчет рентабельности КП», «6 Оплаты Внешняя», «Настройки писем».
- Код скриптов: в `.xlsx` он не попадает.
- Часть формул — функции Google Таблиц; в выгрузке они сохранены вместе с последним посчитанным значением, проверить их работу в файле нельзя.
- Есть обращения к другим таблицам (`IMPORTRANGE`) на листах «5-5 Оформление сделок» и «6 Оплаты» — куда именно, не выписывал.
