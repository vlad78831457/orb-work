# Antigravity CLI (agy) на стенде — заметка

2026-10-21. Поставлен `agy` 1.4.4 в `.tools/agy/agy` (`make agy-setup`). Это консольный агент Google для работы с
кодом — как Claude Code, но на моделях Gemini. По сторонним обзорам, в 2026 он заменил Gemini CLI.
Официальный репозиторий: github.com/google-antigravity/antigravity-cli.

## Как поставлен

Официальный `install.sh` кладёт программу в `~/.local/bin` и сам правит профиль оболочки (`agy install`). Правила
стенда запрещают менять что-то вне `~/pr`, поэтому `tools/agy-setup.sh` повторяет его шаги вручную: манифест →
загрузка → сверка SHA-512 → распаковка в `.tools/agy/`. Профиль не трогается.

Запуск: `.tools/agy/agy` или `alias agy=~/pr/orb-work/.tools/agy/agy`.

## Вход (делает директор)

Первый запуск `.tools/agy/agy` по SSH печатает ссылку входа через Google — открыть на ноутбуке. Другой вариант —
ключ Gemini API. Свои настройки и вход `agy`, скорее всего, хранит в домашней папке (`~/.antigravity`, `~/.config`
или похоже) — это вне `~/pr`, но это его собственные файлы. Я их не открываю.

## Что умеет (по `agy --help`)

- Диалог в терминале. Разовый запрос без диалога: `-p "…"`, ответ можно получить в JSON (`--output-format json`)
  и по схеме (`--json-schema`). Это основа для автоматизации: скрипт задаёт вопрос и разбирает ответ.
- Режимы `plan`, `accept-edits`, `auto`; `--sandbox` — ограничения терминала; `--add-dir` — дать папку.
- MCP-серверы (`agy mcp add …`), плагины, агенты.
- `remote-control` — управление сессией с другого устройства.

## Чему научиться — по шагам

1. Войти, задать простой вопрос по папке `inst/` в режиме `plan` (ничего не меняет).
2. Разовый запрос `-p` с ответом в JSON на неважных данных — например, «перечисли листы в `lis/listy.yaml`».
3. Подключить MCP, если нужен доступ к чему-то ещё.

## Идеи автоматизации (не начаты, решает директор)

- Черновики описаний столбцов (`stolbtsy.yaml`) по формулам — для второго мнения рядом с моими.
- Разбор писем поставщиков в цены и сроки — только на обезличенных данных и только после маски.

**Осторожно:** `agy` отправляет то, что ему дают, в Google. Рабочие данные компании ему не давать, пока директор
не решит, что можно. Это то же правило, что «ничего не выносить наружу».
