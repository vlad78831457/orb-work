# Инструкция по работе с таблицами расчетов (V2)

## 1. Подготовка рабочей таблицы

1. **Откройте чистую таблицу** для работы:
   * Перейдите по ссылке: [Шаблон таблицы расчетов](https://docs.google.com/spreadsheets/d/1FCJJs6AUgq90yVyvy3RWEiuv17h1scgKM2kuBFbdt9w/edit#gid=0).
2. **Проверьте аккаунт**: Убедитесь, что вы авторизованы под рабочей почтой `spreadsheet@haiverk.ru`.
3. **Создайте копию**: В верхнем меню нажмите **Файл** -> **Создать копию**.
4. **Настройте файл**: 
   * В поле названия вставьте скопированное из Битрикс **название сделки**.
   * **ОБЯЗАТЕЛЬНО** поставьте галочку **«Скопировать настройки доступа»**.
   * Нажмите «ОК».
5. **Проверьте результат**: Убедитесь, что открылась новая таблица, и сверьте URL и название.

## 2. Перенос данных из технического задания (ТЗ)

1. Откройте файл с исходными данными (ТЗ), выделите **название товара, единицы измерения и количество**, затем скопируйте их.
2. Перейдите в созданную таблицу на лист **«1-1 Сбор КП»**.
3. **ВАЖНО:** Кликните правой кнопкой мыши и выберите **«Вставить только значения»**, чтобы не сбить форматирование ячеек.
4. **Заполните характеристики:** По аналогии в столбец **E** перенесите характеристики товаров из файла ТЗ.
5. **Очистите пробелы (если они есть):**
   * Выделяем вставленные значения.
   * Переходим в верхнее меню: **Правка** -> **Найти и заменить**.
   * В поле «Найти» введите **один пробел**, в поле «Заменить на» ничего не пишите. 
   * Убедитесь, что выбран правильный диапазон, и нажмите **«Заменить все»**.

## 3. Работа с Начальной максимальной ценой (НМЦ)

> **Что такое НМЦ?**
> Начальная максимальная цена — это предельная стоимость по закупке. Если наша итоговая цена окажется выше НМЦ, нас отклонят или не допустят до подачи заявки. НМЦ всегда прописывается в Извещении (или в приложенных документах: ТЗ, сводных таблицах).

### Виды НМЦ:
1. **НМЦ договора** — суммарная стоимость по всему проекту.
2. **НМЦ за единицу товара** — стоимость конкретной позиции.

### Порядок внесения и проверки:
1. Скопируйте позиционную НМЦ из Извещения и вставьте ее в таблицу (обязательно через *«Вставить только значения»*).
2. Внесите общую **НМЦ договора** в соответствующую ячейку на листе «1-1».
3. **Контроль ошибок:** Сравните общую НМЦ из Извещения с расчетной суммой позиций внизу столбца. Если суммы не равны, значит, порядок позиций в таблице не совпадает с Извещением. Произведите перепроверку.

## 4. Настройка скриптов рассылки (первый запуск)

При первом использовании меню **«E-mail рассылка»** потребуется предоставить доступы Google-скрипту:
1. Нажмите **E-mail рассылка** -> **Удалить лишние строки** (или *Отправить письма*).
2. В появившемся окне нажмите **«Продолжить»** -> выберите аккаунт `spreadsheet@haiverk.ru` (или `ooohajverk@gmail.com` на этапе отправки).
3. Нажмите **«Дополнительные настройки»** -> перейдите по ссылке **«Перейти на страницу (небезопасно)»**.
4. Нажмите **«Разрешить»**.

## 5. Группировка товаров и подготовка запросов

1. **Группировка:** На листе **«1-2 Запросы по товарным группам»** товары объединяются по типу (например: *электротовары, розетки, выключатели*) и по производителю.
2. Выделите нужные товары на листе «1-1» (по одному или целой группой) и скопируйте их на лист «1-2» (столбцы: №, номенклатура, характеристики, ед. изм., кол-во). Номер группы проставится автоматически
