# Репозиторий документации (Артефакты сборки)
```bash

pandoc /src/try01.md --reference-doc=ref_c.docx -o instruction.docx


pandoc index.md  --reference-doc=../../templates/custom-reference-c.docx  -o ../../dist/sostoyanie-rassylki.docx

```
Добро пожаловать в проект автоматизированной сборки документации компании. Проект построен на связке **Markdown + Pandoc + Microsoft Word (.docx)**.

## 📁 Структура проекта

* `build.sh` — главный скрипт сборки. Управляет склеиванием частей и генерацией готовых файлов.
* `src/` — исходные материалы в формате Markdown (`.md`).
    * `_shared/` — модули и скриншоты, общие для **нескольких** документов (например, правила работы в CRM).
    * `process_calc/` — тексты и скриншоты, относящиеся **только** к Смарт-процессу «Расчет».
    * `process_sales/` — тексты и скриншоты, относящиеся **только** к процессу «Продажи».
* `templates/ref.docx` — файл стилей. Изменяя шрифты или цвет ссылок в этом файле через LibreOffice/Word, вы меняете дизайн всех документов сразу.
* `dist/` — папка с готовыми результатами в формате `.docx` (генерируется автоматически).

## 🚀 Как собирать документы

Запустите терминал в корневой папке проекта и используйте одну из команд:

* Собрать только регламент Расчета:  
  `./build.sh calc`
* Собрать только регламент Продаж:  
  `./build.sh sales`
* Пересобрать всю базу знаний разом:  
  `./build.sh all`

## ✍️ Как правильно вести документацию

1. **Изолируйте картинки**: Скриншоты для процесса Расчета сохраняйте строго в `src/process_calc/imgs/`. Никогда не сваливайте медиафайлы в кучу.
2. **Пишите в чистом Markdown**: Используйте заголовки `#`, `##`, списки `1.` и ссылки `[текст](url)`. Не пытайтесь красить текст в самом `.md`.
3. **Переиспользуйте общие части**: Если пишется новая инструкция, где тоже нужно упомянуть авторизацию в Битрикс24 — не копируйте текст. Подключите файл `src/_shared/00_intro.md` в сценарий сборки внутри `build.sh`.
4. **Стили правьте в одном месте**: Если руководство требует изменить шрифт документов или сделать ссылки фирменного цвета — откройте файл `templates/ref.docx` в LibreOffice Writer, нажмите `F11`, измените нужный стиль (например, «Интернет-ссылка») и сохраните шаблон. Пересоберите проект командой `./build.sh all`.
