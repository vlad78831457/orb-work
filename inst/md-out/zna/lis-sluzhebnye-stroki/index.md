# Служебные строки листа

Со слов директора (2026-10-13) и по выгрузке таблицы. Не проверено по коду скриптов.

У большинства листов таблицы расчёта строки 1–9 служебные: их читают **скрипты**. Заголовки для людей стоят в строке 10, данные — с строки 11. Служебные строки не редактируют и не удаляют.

## Что в строках

В столбце C каждой служебной строки стоит её метка.

| Строка | Метка в столбце C | Что в строке |
|---|---|---|
| 1 | `header_first` | начало служебной шапки |
| 2 | `key` | служебные имена столбцов: `Номенклатура`, `НазваниеТовараПоДоговору`… |
| 3 | `formulaColl`, `formulaFree`, `formulaCell` | вид столбца — см. ниже |
| 4–6 | `var_key`, `var_name`, `var_value` | *назначение не описано* |
| 7 | `hide_col` | отметки `Скрыть`, `Сгрупировать`, `СкрытьСгрупировать` |
| 8 | `header_08` | *назначение не описано* |
| 9 | `header_last` | конец служебной шапки |
| 10 | — | заголовки для людей |
| 11 и ниже | — | данные; в столбце C — ключ строки, например `ID_T001` |

## Вид столбца (строка 3)

| Вид | Что это | Что это значит для сотрудника |
|---|---|---|
| `formulaColl` | одна формула на весь столбец | ячейки столбца должны оставаться пустыми: в них выводится результат формулы. Ввод руками сломает столбец |
| `formulaFree` | ячейки свободные, но в них может вводить пользователь | введённое значение скрипт запоминает на служебном листе; сама ячейка рано или поздно снова освобождается под результат формулы |
| `formulaCell` | формула в каждой ячейке, по шаблону | при добавлении новой строки формула должна появиться в ней сама |
