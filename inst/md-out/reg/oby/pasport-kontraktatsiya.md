# Ведущий раздел «Контрактация» паспорта

Записывает в паспорт проекта даты и сведения о договоре: протокол итогов, сроки подписания, когда пришёл проект договора.

- **Обязанность:** одна, один ответственный. Ключ: `pasport-kontraktatsiya`
- **Предполагаем, что выполняет:** [Менеджер по продажам](../../reg/rol/prodazhi.md)
- **Контур:** 0
- **Почему выделили:** Отдельная ответственность за данные в таблице — их потом читают другие.
- *Черновик — проверить.*
