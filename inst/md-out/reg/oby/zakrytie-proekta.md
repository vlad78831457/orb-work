# Закрывающий проект

Считает финансовый результат, пополняет фонд косвенных расходов, анализирует план-факт и ставит статус «Закрыт».

- **Обязанность:** одна, один ответственный. Ключ: `zakrytie-proekta`
- **Предполагаем, что выполняет:** *не знаем*
- **Контур:** 0
- **Почему выделили:** В регламенте у процесса нет исполнителей.
- **Догадка, не подтверждено:** Кто — не указано; «согласно Регламенту по закрытию проектов».
- *Черновик — проверить.*
