# Ведущий папку проекта

Создаёт «Рабочие документы» и «Контрактация», открывает доступ исполнению, раскладывает документы заявки и договора.

- **Обязанность:** одна, один ответственный. Ключ: `papka-proekta`
- **Предполагаем, что выполняет:** [Менеджер по продажам](../../reg/rol/prodazhi.md)
- **Контур:** 0
- **Почему выделили:** В «Структуре папок» эти папки создаёт и наполняет менеджер по продажам; одна ответственность — порядок в папке.
- *Черновик — проверить.*
