# Термины

<a id="crm"></a>**CRM** — CRM (Customer Relationship Management) – система для управления сделками, клиентами, смарт-процессами. В проекте используется Битрикс24. *(проверить)*

<a id="kp"></a>**КП** — Коммерческое предложение – ответ поставщика на запрос, содержащий цену, сроки поставки, условия. *(проверить)*

<a id="nmts"></a>**НМЦ** — Начальная (максимальная) цена договора – сумма, которая указывается в извещении о тендере. Не содержит налоги и сборы. *(проверить)*

<a id="okpd2"></a>**ОКПД 2** — Общероссийский классификатор продукции по видам экономической деятельности. Код ОКПД 2 используется для классификации товаров и услуг в тендерах. *(проверить)*

<a id="postavshchik"></a>**Поставщик** — Поставщик – организация, которая производит или продает товары. В проекте работаем с заводами-изготовителями и их дилерами. *(проверить)*

<a id="smart-protsess"></a>**Смарт-процесс** — Смарт-процесс – гибкий инструмент Битрикс24 для управления бизнес-процессами. В проекте используется смарт-процесс 'Расчет' для управления тендерами. *(проверить)*

<a id="tender"></a>**Тендер** — Тендер – процедура конкурентной закупки товаров или услуг. В проекте работают с государственными и коммерческими тендерами. *(проверить)*
