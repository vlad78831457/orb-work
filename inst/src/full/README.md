# Сводные полные документы

Сюда кладутся описания полных документов, которые собираются **из нескольких инструкций** и не принадлежат одной части.
Описание полного документа одной инструкции лежит рядом с ней: `inst/src/md-kod/tio/<часть>/full.yaml`.

Файл `<имя>.yaml`:

```
title: "Название документа"
chast: tio.tab-raschet        # с какой части начинается
vklyuchit:                    # что вставить после неё, по порядку
  - tio.tov-razdelenie
  - lis.k2-5-4-izmeneniya
```

Сборка: `make full F=<имя>` → `inst/md-full-out/full/<имя>.md`.
