# Закупка: кто что делает

По регламенту «Распределение задач Контрактация — Исполнение», лист «10.10.2026 Версия К» (`raw/2026-10-19-ak-xls`). Это второй контур — [[zna.tab-kontury]].

В регламенте у каждого шага отмечены роли: **исполнитель** делает работу, **соисполнитель** помогает, **согласование** — с кем согласуют до решения. Перечень не задаёт строгий порядок: шаги могут идти параллельно.

## Осталось сделать

- В регламенте шаги 19–24 делят два человека: один проверяет счета, ведёт 1С и таблицу оплат, другой оплачивает. Здесь оба записаны как [[rol.kaznachey]] — проверить.
- В регламенте отдельно отмечена роль «АС» — по шагам доставки это, видимо, [[rol.logist]]. В закупке она не участвует.
- Шаги 3–6 в регламенте помечены «будет пересмотрен под изменение таблицы в части закупок» — сверить с листами 5-x.
