# **Критерии группировки товаров**

**Цель процесса**: Распределить спецификацию по одноуровневым категориям, чтобы исключить нецелевую рассылку запросов (спам) поставщикам. Каждый контрагент должен получать письма строго по своему профилю деятельности.

---

## **1. По типу товара**
**Описание**: Объединение позиций по их функциональному назначению.
**Правила выявления**:
1. Анализ наименования на ключевые слова (например: *«вилка»*, *«кабель»*).
2. Проверка столбца *«Характеристики»* на маркеры типа (например: *«220V»*, *«IP65»*).
3. Ручная классификация позиций с неочевидной принадлежностью.

* **Пример**: *«Кабель NYM 3x1.5»* → группа *«Электротовары / Кабели и провода»* (по ключевому слову «кабель»).

---

## **2. По производителю**
**Описание**: Группировка товаров по бренду или заводу-изготовителю.
**Правила выявления**:
1. Поиск имени бренда в наименовании или столбце *«Производитель»*.
2. Сопоставление через базу синонимов и дочерних брендов (например: *Bticino* → группа *Legrand*).
* **Пример**: *«Розетка Legrand Mosaic»* → группа *«Legrand»* (по совпадению бренда).

---

## **3. По ключевым словам и характеристикам**
**Описание**: Связывание специфических параметров со специализацией поставщика.
**Правила выявления**:
1. Сканирование наименования и технических столбцов на уникальные маркеры (например: *«RJ45»*, *«Класс безопасности 4»*, *«Сейсмостойкость III»*).

* **Пример**: Характеристика *«Защита IP67»* → подбор поставщиков, специализирующихся на пыле-влагозащищенном оборудовании.

---

## **4. Альтернативный метод: Группировка с помощью AI (Нейросетей)**
**Описание**: Профессиональная компетенция специалиста, позволяющая автоматизировать процесс классификации и подбора кодов через языковые модели (ChatGPT, Claude, YandexGPT и др.).

**Правила применения**:
1. Исполнитель использует **готовый рабочий промт** (см. Приложение №1).
2. В конец промта вставляется необработанный список товаров (допускается копирование напрямую из Таблицы с сохранением ID строк и характеристик).
3. Нейросеть автоматически выполняет комплексный анализ (по типу, бренду, спец-свойствам), распределяет позиции по плоским группам и подбирает цифровые коды **ОКПД 2**.
4. Специалист проводит верификацию (проверку) полученного от AI результата перед загрузкой в CRM/ERP.

---

## **Приложение №1. Готовый промт для AI**

```text
Ты — эксперт по автоматизации закупок, категорийному менеджменту и работе с классификаторами продукции.

Моя цель: автоматически распределить список товаров по плоским (одноуровневым) категориям и подобрать код ОКПД 2 для каждой позиции. 
Главная задача: сгруппировать позиции так, чтобы исключить ошибочную рассылку (спам) поставщикам. Если компания поставляет товары из одной группы, она не должна получать письма по товарам из другой.

При классификации жестко руководствуйся следующими правилами и критериями:

1. Группировка по типу товара и ключевым словам (Из регламента):
- Сканируй название товара на наличие корневых ключевых слов (например, "насос", "вентилятор", "клапан", "уплотнение"). 
- Объединяй товары со схожим функционалом в одну укрупненную категорию.

2. Группировка по производителю и бренду (Из регламента):
- Ищи в названии бренда производителя (например, "Лиссант", "SNR"). Если бренд указывает на узкую специализацию компании (например, SNR — подшипники и уплотнения), используй это для точного определения категории.

3. Группировка по характеристикам (Из регламента):
- Анализируй сопутствующий текст в кавычках (класс безопасности, категория сейсмостойкости). Специфические свойства (например, Сейсмостойкость I или III для АЭС/опасных объектов) указывают на то, что поставщик должен иметь особые лицензии. Учитывай это, чтобы товары для обычного общепрома и спец-объектов не смешивались, если это критично для рынка поставщиков.

Правила вывода результата:
- Выведи строго плоский список категорий (БЕЗ подкатегорий). Каждая категория — это готовый рынок для рассылки пула поставщиков.
- Внутри категорий выведи позиции списком.
- ОБЯЗАТЕЛЬНО сохраняй исходную нумерацию строк (ID) перед названием товара. Не схлопывай одинаковые товары с разными ID.
- ОБЯЗАТЕЛЬНО сохраняй сопутствующие характеристики товара в кавычках.
- В конце каждой строки через тире ДОБАВЬ наиболее точный цифровой код ОКПД 2 (от 4 до 9 знаков).
```
