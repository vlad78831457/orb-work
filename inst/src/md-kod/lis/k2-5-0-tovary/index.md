# Лист «5-0 Товары»

**Назначение**

**Автоматический** лист: собирает данные для работы всего контура закупки. Аналог листа **1-0 Товары** для контура 2.

Берёт товары с листа **[[lis.k2-5-0-peredacha:kratko]]** (основной источник) и поправки с листа **[[lis.k2-5-4-izmeneniya:kratko]]**. Отсюда данные расходятся по остальным листам контура.

**Кто работает:** никто — лист полностью автоматический.

## Устройство

По выгрузке таблицы от 2026-10-13 (отрывок); контур 2 — [[zna.tab-kontury]].

- Размер: `A1:Z310`; закреплено до ячейки `A11`. Формул: 1, заполненных ячеек без формул: 144.
- Лист собран по общему каркасу: строки 1–9 служебные, заголовки для людей — в строке 10, данные — с строки 11. Что значат служебные строки и «вид» столбца — [[zna.lis-sluzhebnye-stroki]].
- Берёт данные с листов: «1-1 Сбор КП».
- Данные этого листа используют: «5-1 Сбор КП Закупки», «5-3 Выбор поставщиков Закупки», «S-10 Топ 5-3».
