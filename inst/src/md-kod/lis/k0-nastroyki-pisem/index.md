# Лист «Настройки писем»

Таблица: таблица проекта · контур 0.

**Зачем** (со слов): настройки писем.

Устройство листа — заголовки, вид столбцов, списки, формулы, связи с другими листами — собрано из таблицы ниже. Строка заголовков на этом листе угадана по закреплённой области — проверить.

## Зачем лист — подробно

Кроме настроек рассылки (лимит писем, перенос строки в подписи, метка повторной рассылки «♠» и т. п.), здесь лежат
**справочники** — значения для выпадающих списков на других листах и правила, которые от них зависят. По заголовкам
(строка 1) и выпадающим спискам других листов (собрано 2026-10-20):

| Столбец | Справочник | Где используется |
|---|---|---|
| AL | Статусы запроса | 5-1, столбец «Запросить» |
| AM, AN | Нужна экспертиза, Решение эксперта | AN — 3-2, решение эксперта по каждому предложению; AM — не найдено |
| AO | Нац режим 1875 | 1-1 |
| AU, AV, AW | Условия оплаты, Куда доставить груз, Обязательства поставщика по доставке | 5-5 (AV — список не подключён) |
| AX | Статус закупщика — статусы сделки по товару | 5-5 «Статус», 5-3 «Статус» |
| AY, AZ, BA | при каких статусах обязательны «Реальная цена», «Реальный срок», «Условия получены» | 5-5 |
| BE | Статусы экспертизы | 3-2, столбец D |
| BF | Аналог | 4-3, столбец T |
| BB, BC, BD | Статусы звонков, Статусы проекта, Правила приёмки | списками не используются — проверить |
| AC | служебные вычисления | 4-2 (столбцы O, AA, AM) |
| BG | НДС | 5-5 |
| BH | проверка обязательных столбцов листа 5-5 | 5-5 |
| BQ | Вид оплаты | 5-5 |

Похоже, это и есть справочники жизненных циклов: статусы закупщика (AX) и правила к ним (AY–BA, BH) — динамические,
остальные списки — статические. Подтвердить.

## Как заполнять

*Заполнить:* какие столбцы вводят руками, какие считаются сами. Что значит каждый столбец — в `stolbtsy.yaml` рядом (поля `chto` и `kak`).
