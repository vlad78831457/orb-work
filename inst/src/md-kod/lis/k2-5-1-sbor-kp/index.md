# Лист «5-1 Сбор КП Закупки»

**Назначение**

Здесь все товары контура, по ним собираются предложения поставщиков. Товары попадают сюда с листов **5-0** и **5-4** через лист **5-0 Товары**.

*Записано коротко, чтобы закрыть инструкцию «Разделение товаров»; подробности — позже.*

## Устройство

По выгрузке таблицы от 2026-10-13 (отрывок); контур 2 — [[zna.tab-kontury]].

- Размер: `A1:CZ319`; закреплено до ячейки `J11`. Формул: 3132, заполненных ячеек без формул: 428.
- Лист собран по общему каркасу: строки 1–9 служебные, заголовки для людей — в строке 10, данные — с строки 11. Что значат служебные строки и «вид» столбца — [[zna.lis-sluzhebnye-stroki]].
- Берёт данные с листов: «5-0 Товары», «5-2 Запросы КП Закупки», «1-1 Сбор КП», «S-10 Предложения», «0-Паспорт проекта».
- Данные этого листа используют: «5-0 Передача в закупку», «5-3 Выбор поставщиков Закупки», «5-5 Оформление сделок», «S-10 Оформление сделок ID_Товар», «7-2 Документация исполнение», «S-10 Предложения».
