# orb-work

**orb-work** — рабочий проект директора: инфраструктура на Google Sheets (таблицы, формулы, скрипты) и всё, что вокруг неё.
Имя — от англ. *work* ← пие. *werǵ- «делать».

Репозиторий закрытый. Рабочие таблицы живут в Google; здесь — их описание, код скриптов, инструкции и сырые материалы.

## Как читать

| Файл | Что там |
|---|---|
| [CONTOUR.md](CONTOUR.md) | где идёт работа: стенд `ag12`, как войти, что сделать один раз |
| [CLAUDE.md](CLAUDE.md) | контекст и правила для агента |
| [STATUS.md](STATUS.md) | одна страница: что сделано, что в работе, что ждёт решения |
| [GOALS.md](GOALS.md) | цели G-001…: зачем, когда готово |
| [inst/](inst/) | инструкции для пользователей (G-001) |
| [raw/](raw/) | сырое: выгрузки таблиц и скриптов, старые инструкции, заметки — как есть |
| [think/](think/) | рассуждения |

Ветки — `task/`, `think/`, `try/` с индексом `aa`, `ab`…; последовательность своя у этого проекта. Проверка — `make test`. Сборка инструкций — `make inst`.
